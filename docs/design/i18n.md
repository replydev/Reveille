# Languages

Reveille follows the phone's language, or the per-app language set in Android Settings → Apps → Reveille → Language (Android 13+). There is no in-app picker.

## Supported locales

| Locale | Folder | Status |
|---|---|---|
| English (en-US) | `values/` | Source |
| Italian (it) | `values-it/` | Reviewed by the owner (pending) |
| Spanish (es) | `values-es/` | Draft, needs native review |
| French (fr) | `values-fr/` | Draft, needs native review |
| German (de) | `values-de/` | Draft, needs native review |

## Rules

- `app/src/main/res/values/strings.xml` (English) is the source. Every other locale has every key, in the same order. `app_name` is `translatable="false"`.
- Lint treats `MissingTranslation` and `ExtraTranslation` as errors (`app/lint.xml`), so a key added in English without a translation fails the build check.
- Keep format arguments identical (`%1$s`, `%2$d`, `%d`); reorder them freely where the grammar needs it.
- Plurals: `one` and `other` everywhere. Italian, Spanish and French also define `many` (CLDR uses it for millions); it repeats `other`.
- Italian and French use the typographic apostrophe (’), so nothing needs escaping. French puts a no-break space before `:` `?` `!` and inside « ». Quotes are « » in Italian, Spanish and French, „ “ in German.
- Register: informal in Italian (tu), Spanish (tú) and German (du); French uses vous.
- Labels for Android and HyperOS settings (for example "Unrestricted", "Other permissions") follow the wording those systems use in the language, so users can find them.
- Buttons, chips, tabs and overlines stay short. Long German and French text either wraps or ellipsizes.

"Policy" is a named recurring schedule (for example "Work", weekdays at 7:00); "One-off" is an alarm on a single date. French uses "Paramètres" (Android's own term) rather than "Réglages".

## Adding a language

1. Copy `values-it/strings.xml` to `values-xx/strings.xml` and translate every string, keeping the key order and the format arguments.
2. Add the plural quantities the language needs; lint's `MissingQuantity` warning names any that are missing.
3. `generateLocaleConfig` picks the folder up, so Android lists the language in the per-app setting. Nothing else to register.
4. Add the language to the table above and its terms to the glossary.
5. Add an assertion to `app/src/test/java/com/replydev/reveille/text/TranslationsTest.kt`.
6. Run `./gradlew :app:lintDebug` (0 errors) and check the long-text screens on the emulator with `adb shell cmd locale set-app-locales com.replydev.reveille --locales xx`.
